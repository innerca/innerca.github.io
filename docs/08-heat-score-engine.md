# 论文热度计算引擎 · 技术方案 v2.0

## 1. 目标

为知识库中的每篇论文计算一个动态、客观、分领域的热度分数 (Heat Score)，综合学术影响力、社区关注度、可复现性、时效性与来源权威性，通过类艾宾浩斯遗忘曲线衰减，支持经典论文识别、自动沉底与复活。

系统在每次站点构建时增量更新，前端始终拿到最新排名。

---

## 2. 核心公式

```
领域内热度分 = (
    领域内引用速度得分 × 30 +
    领域内社区热度得分 × 25 +
    领域内可复现性得分 × 20 +
    时间新鲜度得分 × 15 +
    来源权威性得分 × 10
) × 时间衰减系数 + 复活临时加分

全局热度分 = 领域内热度分 × 领域活跃度权重
```

所有子项得分已归一化到 [0, 1]，系数总和 100。

---

## 3. 领域划分与统计

### 3.1 领域分类

使用 arXiv 二级分类作为基础。一篇论文所属领域取其主分类。常见类别：cs.AI, cs.CL, cs.CV, cs.LG, cs.RO, cs.IR, stat.ML 等。

若论文来自非 arXiv 数据源，通过 LLM 在总结时预测最可能的 arXiv 分类。

### 3.2 领域统计数据 (`field_stats.json`)

使各子项得分在领域内进行比较，需预计算每个领域的基准统计量。每周更新一次。

```json
{
  "cs.CV": {
    "paper_count": 15234,
    "avg_citation_velocity": 0.23,
    "p95_citation_velocity": 1.8,
    "avg_buzz_score": 0.12,
    "p95_buzz_score": 0.6,
    "avg_code_score": 0.15,
    "p95_code_score": 0.8,
    "updated_at": "2026-05-07"
  }
}
```

若无足够数据（论文数 < 100），采用全局统计值兜底。

## 4. 子项计算

### 4.1 引用速度得分（权重 30）
- 数据来源：Semantic Scholar `citationCount`
- 公式：`raw_velocity = citationCount / (days_since_pub + 1)`
- 归一化：`S_cite = clamp(raw_velocity / p95_citation_velocity, 0, 1)`

### 4.2 社区热度得分（权重 25）
- 数据来源：Hugging Face Daily Papers 推荐状态，Twitter 提及
- 被 HF 推荐：0.8；有其他社交提及：0.5；无：0
- 冷静期：发表 ≤72h 的论文该得分 ×0.5，防止初期炒作虚高

### 4.3 可复现性得分（权重 20）
- 数据来源：Papers with Code / GitHub 仓库
- 存在官方代码：1.0；存在社区复现：0.5；期待分：0.3；无：0

### 4.4 时间新鲜度得分（权重 15）
- `S_fresh = max(0, 1 - days_since_pub / 1095)`（3 年线性衰减至 0）

### 4.5 来源权威性得分（权重 10）
- 顶会 (NeurIPS, ICML, CVPR 等)：1.0
- 知名会议 (AAAI, EMNLP, ICRA 等)：0.8
- 其他：0.3

---

## 5. 时间衰减系数

采用类艾宾浩斯遗忘曲线：

- 前 7 天：`1.0`（新论文红利期）
- 7-30 天：`0.5 ^ ((days - 7) / 20)`（半衰期约 20 天）
- 30 天后：永不低于 `0.05`（保留长期价值）

---

## 6. 复活机制

当发表 >90 天的旧论文引用突然激增时加分：

- 触发：过去 30 天新增引用 > 前 360 天均值 ×3
- 加分：固定 20 分，有效期 14 天，21 天归零

---

## 7. 经典论文识别

满足任一即标记 `is_cornerstone = true`：
- 总引用 ≥ 500
- 发表 >3 年且近一年引用 ≥ 50
- 来源权威性 ≥ 0.8 且总引用 ≥ 200

基石论文永不沉底，每季度 AI 重新评估。

---

## 8. 沉底与过滤

- 阈值：领域内热度分 < 30 → `hidden = true`，前端默认不展示
- 基石论文永不沉底
- 沉底论文每月扫描一次，引用突增可恢复
