# 🎨 前端界面参考：赛博学术雷达 (MVP)

## 整体氛围
- 深空黑背景，如透过飞船舷窗看星云
- 青紫色发光边框与渐变文字，营造全息投影感
- 半透明毛玻璃面板悬浮于动态粒子背景之上
- 所有交互都有丝滑的微动画，仿佛操作未来控制台

## 🧩 核心组件视觉规范

### 1. 导航栏 (Navbar)
- 半透明深色背景：`rgba(11,15,25,0.75)`
- 底部 1px 青紫渐变线
- 当前页面链接下方有发光线
- 语言切换按钮为地球图标，悬停显示语言选项
- 搜索图标点击后展开输入框（移动端全宽）

### 2. 粒子背景 (ParticleBackground)
- 60～80 个缓慢移动的光点，颜色在青紫之间渐变
- 当两个光点距离小于 120px 时，画一条透明度随距离变化的连线
- 整体移动速度极慢，不分散注意力

### 3. Hero 区域
- 大标题用渐变文字（青→紫），带微弱闪烁光标动画
- 副标题用等宽字体，打字机效果（逐字出现，一次性动画）
- 底部一条动态的“数据流”分隔线（可省略）

### 4. 统计面板 (StatsBar)
- 两个垂直排列的计量方块
- 数字用等宽字体，颜色青，从 0 滚动至目标值
- 标签文字淡色，下方有微弱的进度条装饰

### 5. 论文卡片 (PaperCard) — 复用率最高
- 毛玻璃深色背景，1px 半透明青边框
- 悬浮时上浮 4px，边框变亮，出现外发光
- 内部布局：
  - 顶部：标题（语言按当前路由），单行溢出省略
  - 中部：两行摘要，颜色淡
  - 底部：标签组（霓虹边框小药丸）+ 日期 + 引用数图标
- 若 `isTrending` 为 true，右上角有🔥或脉冲光点标记

### 6. 趋势论文横向滚动区
- 左右有渐变遮罩暗示可滑动
- 卡片宽度固定，间距均匀，自动循环播放（可选暂停）
- 支持触摸拖拽和鼠标滚轮

### 7. 最新论文列表
- 纵向卡片堆叠，单体与趋势卡片相同
- 使用加载更多按钮（霓虹边框幽灵按钮），点击增加显示数量

### 8. 论文详情页
```

┌──────────────────────────────────────┐

│  │ 标签 │ │ 标签 │ │ 标签 │        │

```

### 9. 搜索页
- 搜索框居中，大号，获得焦点时边框青色发光
- 下方实时显示结果计数，结果列表复用 PaperCard
- 空结果展示故障风格插画（GlitchText）

### 10. 页脚
- 简单深色背景，无边框
- 链接用淡色，悬停变青

## 🎬 动画清单
| 交互/元素 | 动画描述 |
|------------|----------|
| 页面进入 | 整体淡入 (opacity 0→1, duration 0.2s) |
| 卡片悬浮 | 上浮 4px + 外发光 + 背景增亮 |
| 卡片点击 | 轻微缩小 (0.98) |
| 统计数字 | 从 0 滚动到目标值，弹簧物理 |
| 列表交错 | 子元素依次出现，延迟 0.05s |
| 趋势区滚动 | 自动向左平移，悬停时暂停 |
| 搜索框聚焦 | 边框颜色过渡为青，宽度短暂增加 |
| 粒子背景 | 每帧更新位置，连线透明度渐变 |

## 📱 响应式策略
- **桌面 (>1024px)**：双列或三列网格，导航水平，搜索框内联
- **平板 (768–1024px)**：两列卡片，导航保持不变
- **手机 (<768px)**：单列，导航改为汉堡菜单，搜索框折叠在菜单内或独立行，卡片间距缩小
